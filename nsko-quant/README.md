# NSKO QUANT · by NSKO Solutions

Trade the markets. Automatically.

- `app/` desktop app front end (React + TypeScript + Vite). Stage 1 runs on the DEMO DATA simulator.
- `assets/brand/` lockups (dark, light) and the 1024 px app icon.
- `docs/` decisions log, stage reports, screenshots.
- `tools/shots.cjs` screenshots every page.

Run it: `cd app && npm install && npm run dev`, then open the printed address.
