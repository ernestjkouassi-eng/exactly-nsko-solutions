One-time setup

Set your HQ password

HQ is locked until you choose a password. It is stored as a secret in Cloudflare, never in the website's code. It takes about two minutes.

  1. Sign in at dash.cloudflare.com.
  2. Open Workers & Pages, then click nsko-solutions.
  3. Go to Settings, then Variables and Secrets, and click Add.
  4. Choose type Secret. Name it HQ_PASSWORD. For the value, type a long password only you know (four or more random words works well).
  5. Click Deploy. Then reload this page and sign in.

Keep the password somewhere safe, such as a password manager. To change it later, edit the same secret; everyone signed in is signed out straight away.
